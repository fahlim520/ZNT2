# 轻任务 · 顶部滑出任务管家

一款 Windows 桌面待办工具，复刻经典 QQ 的顶部贴边体验：鼠标移到窗口所在位置的屏幕顶部，任务窗口自动滑出；移开后快速收回。支持自然语言添加任务、导入文档和截图、本地保存和提醒回复。

## 下载试用

适用于 Windows 10 / 11，64 位。试用者无需安装 Node.js 或下载源码。

**[前往 Releases 下载试用版](https://github.com/fahlim520/ZNT2/releases/latest)**

- `qing-task-*-windows-x64-setup.exe`：Windows 64 位安装版，可选择安装目录；安装完成后自动创建桌面和开始菜单快捷方式。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

首次启动先填写校园资料，再配置**自己的 DeepSeek API Key**。资料中不确定的内容可留空，学习阶段可选“暂不填写”；Key 也可先跳过，用“手动添加”创建任务。程序内及安装文件的产品名称为“轻任务”。

## 校园资料与针对性提醒（0.4.0）

- 首次使用填写学习阶段、学校、专业 / 学院、校园身份与关注事项。旧版用户更新后也会看到一次引导；以后可从“设置 → 我的校园资料”修改。
- 校园资料保存在本机。**“允许 AI 使用校园资料”默认关闭**；开启后，AI 整理通知或任务时才会附上学校、专业、阶段、身份、关注事项，发送给 DeepSeek。无需填写姓名、学号、电话。
- 开启后，导入通知会显示“与你相关 / 需要补充确认 / 适用条件可能不符 / 公共事项”、判断理由与通知对象原文。未知资料不会视为不符合；不相关的候选也会保留供核对，不会静默删除。
- 缺少资格或日期信息时显示具体问题。在“本次补充”填写回答后重新整理；补充会发送给 DeepSeek，但不会自动改写个人资料。AI 判断需用户核对后勾选保存。
- 只有日期的**新任务**可选择“当天每小时、之前每天一次”，或“每天在指定时刻提醒”。若今天到期且每日时刻已过，在 5 分钟内提醒（不晚于当天截止）。此偏好即使不允许 AI 读取校园资料，也会在本地执行。
- 明确的“今天 21 点提醒”、自定义提前提醒和“不提醒”保持原意，不自动提前一小时。修改偏好不重排已有任务；提醒未回复仍在 5 分钟后重试。

这是早期试用版，安装文件暂未进行代码签名。应用需要保持运行才能发出提醒；隐藏窗口后仍在系统托盘运行，通过托盘菜单“退出轻任务”可完全退出。

## 使用方式

- 鼠标移到窗口所在位置的屏幕最顶端展开；移开后快速收回并完全隐藏，不留下标签、线条或透明触发窗口。也可点击托盘图标展开。
- 拖动展开窗口的标题区域，沿屏幕顶部移动；移动后在新的位置触发。收起按钮可立即收起，正在输入或核对时保留展开。
- 拖动右边调宽、底边调高、右下角同时调整宽高；位置和尺寸会自动保存。设置中可“恢复默认大小”。
- **Enter 发送，Shift+Enter 换行**；中文输入法确认选字时不会发送。
- 支持勾选完成、编辑、删除、搜索以及工作 / 生活 / 学习等分类。
- 点击“贴边自动隐藏”可固定展开，再点一次恢复自动隐藏。
- 设置中可选择伊藤橙（橙色）、酷安绿（绿色）、韵味紫（紫色）、哔哩粉（粉色）四种主题，并实时预览、保存选择。

## 文档与截图转待办（0.2.0）

- 把文件拖进展开的窗口，或点击输入框上方的“导入文件”。截图可以直接按 **Ctrl+V**，也可以点击“粘贴截图”。微信公众号通知可以截图后导入。
- 支持 **PDF、Word（DOCX / DOC）、PNG / JPG / JPEG / BMP / WebP 图片、TXT、Markdown、CSV**。不支持的格式请先导出为 PDF 或截图。
- 文字版 PDF 和 Word 在本地提取文字；扫描 PDF 与截图使用 Windows 本地 OCR。OCR 需要系统安装对应语言的“光学字符识别”组件，本机没有组件时会提示。
- 配置 Key 后，AI 从识别文字中整理多条待办。先核对任务、日期、提醒方式和来源摘录，可以修改或取消勾选，再点击“加入待办”。未配置 Key 也能提取文字并手动创建任务。
- 明确的“15:05 提醒我”保留该时刻；未指定提醒时间的明确截止时刻默认到点提醒。只有日期时，当天按小时提醒，未来日期在今天及中间各天安排一次，截止日按小时提醒。
- 缺少年份、相对日期缺少通知发布日期、已经过期或疑似重复的事项会提示核对，默认不勾选，避免把旧通知自动安排成今天的任务。
- 每批最多 8 个文件、每个 20 MB；每份 PDF 最多前 20 页，每批最多 5 万字和 40 条任务。超限会提示，长文件请分批导入。
- Word 内嵌图片暂不识别，请将图片另存或截图后单独导入。OCR 结果可以在预览中修正后重新整理。

## 提醒排队与添加反馈（0.4.2）

- 同时到期的任务逐条排队，显示剩余条数；新提醒或五分钟重试不会替换当前任务，也不会清空正在输入的回复。同一批只播放一次提示音、发送一条汇总系统通知。
- 回复完成或延后后自动显示下一条；暂不回复会保留本次运行中的回复草稿，下次重试时可继续。完成、删除或改期后，点击旧系统通知不会重新弹出已失效的提醒。
- 自然语言或手动新增后，直接显示实际提醒时间 / 周期；未设时间会明确显示“不提醒”。反馈条保留 15 秒，提供“修改”和“撤销”，不增加确认弹窗。撤销恢复原输入；已经编辑或完成的任务不会被旧撤销按钮删除。
- **Ctrl+Alt+Q** 随时呼出并聚焦输入框；设置中可按下新的组合键或直接填写，留空关闭。冲突时会提示，原快捷键仍可用。正在编辑或回复时不会跳走。Esc 在主界面收起窗口并保留输入，在编辑弹窗中先关闭弹窗。
- 本版同时发布此前本地试用的通知去重、确认更新时间，以及原生窗口完全隐藏功能。

## 通知去重与时间更新（0.4.1，随 0.4.2 发布）

- 重复导入通知时，预览显示“已有这条提醒”，默认不再次创建。已完成任务也不会因重复导入而恢复提醒。
- 补充通知明确修改同一事项时间时，预览显示原截止 / 原提醒与新时间。单独勾选“确认更新原任务时间”后更新同一条记录，保留原名称、分类、个人备注和完成状态，并记录来源。
- 若不是同一件事，可以选择“这是另一件事，另建提醒”。更新后重复导入旧通知，不撤销现有安排；最近 20 个通知版本保留在本地以便识别。
- 普通任务先展示名称和时间，“调整时间和分类”默认折叠；需要补充信息时才展开追问。不增加项目或进度管理界面。
- 语义对照每次最多使用 60 条已有文件任务，按与新通知标题的相似度和更新时间选择；本地完全一致的核对覆盖全部文件任务。不同活动、届次、行动或缺少变更依据时不应合并，AI 的关联建议仍需用户核对。
- 保存更新前再次核对原任务是否被修改或删除；若预览已经过时，要求重新整理，不覆盖用户的新修改。

## 提醒示例

日期和时间按中国时区 `Asia/Shanghai` 理解。

| 输入 | 提醒行为 |
| --- | --- |
| 今天 15.05 提醒我整理电脑 | 今天 15:05 提醒，不改成一小时后；若该时刻已过，运行中的应用会补提醒 |
| 今天我要整理电脑 | 创建今天的任务，按校园资料中的日期提醒偏好安排；默认通常在一小时后首次提醒 |
| 明天下午 3 点开会 | 截止明天 15:00，默认到点提醒 |
| 明天下午 3 点开会，提前 10 分钟提醒 | 明天 14:50 提醒 |
| 整理书架，不要提醒 | 保留待办，不安排提醒 |

提醒弹出后，直接用自然语言回复即可：轻任务会让 DeepSeek 判断你是在确认完成（例如“好的”“收到，我马上处理”“hao”），还是要求延后（例如“30 分钟后再提醒我”“明天上午 9 点再提醒我”）。没有 Key 或网络暂时不可用时，会用本地规则兜底；无法确定时会请你补充，而不会强迫输入某个固定词。没有回复时，五分钟后再次提醒。AI 解析失败会保留原始输入，供手动确认。

## 提醒提示音（0.3.2）

- 设置中可以开启或关闭自定义提醒提示音。
- 程序内置“冰、牛、哇哦”三个默认提示音，首次启动会放入音频文件夹，无需另行下载。已有自定义音频时保留原有文件；旧版的音频文件夹会优先迁入新目录。
- 点击设置中的“打开音频文件夹”，把自己的音频放进去即可。音频保存在当前 Windows 用户的应用数据目录中（`%APPDATA%\qing-task\reminder-audio`），避免向受 Windows 保护的“文档”目录写入；已有旧版音频会自动复制迁移，原文件保留。新增或删除音频后无需重启，下次提醒会重新读取。
- 支持 `.wav`、`.mp3`、`.m4a`、`.aac`、`.flac`、`.ogg` 和 `.webm`。按文件名排序，每次提醒播放一个文件，下一次提醒播放下一个，播到最后一个后回到第一个。可用 `01`、`02`、`03` 等文件名前缀控制顺序。
- 文件夹为空或暂时无法读取时，使用程序内置的默认音频。
- 三个默认音频随源码和安装包提供。用户自行添加的音频只保存在本机，不会上传到 DeepSeek 或 GitHub。

## API Key 与隐私

- 项目源码和发行包均不包含开发者的 API Key、个人任务或本机设置。每位使用者自行配置 Key，API 费用由自己的 DeepSeek 账号承担。
- Key 仅在 Electron 主进程使用，通过 Windows `safeStorage` 加密后保存在当前用户的应用数据目录；设置页可以修改或删除。
- 任务默认只保存在本机，没有账号系统或云端同步。
- 使用自然语言解析时，输入的任务描述和解析所需的当前时间会通过 HTTPS 发给 DeepSeek；测试连接也会向 DeepSeek 发送请求。手动添加任务不调用 AI。
- 文档和图片原件不上传。配置 Key 后，导入时提取的文字与文件名会发送给 DeepSeek；可以在预览中修改文字并重新整理。关闭导入不会保存候选任务，确认加入后只在本地保存任务和来源摘录。
- 本次补充说明也会发送给 DeepSeek，并随确认的任务保存为备注。校园资料只有在明确开启 AI 使用开关后才会随整理请求发送；可在设置中关闭或清空选填项。资料没有独立账号或云同步。
- 通知去重和补充通知分析会把选中的已有文件任务标题、截止日期、完成状态和来源摘录发送给 DeepSeek。不会发送手动任务、个人备注、完整设置或 Key 到模型消息中。没有 Key 时仍可手动导入，本地完全一致的任务会在保存时去重。
- 本地配置、任务数据、日志和工作目录已加入 `.gitignore`。请不要在 Issue、截图、日志或代码中提交任何真实 Key。

## 本地开发

建议使用 Node.js 22 LTS，在 Windows PowerShell 中运行：

```powershell
git clone https://github.com/fahlim520/ZNT2.git
cd ZNT2
npm ci
npm run dev
```

如 Electron 运行包下载超时，请在网络恢复后重新运行 `npm ci`。开发运行仍需自己在设置页填写 Key，无需创建任何密钥文件。

## 验证与打包

```powershell
npm run typecheck
npm test
npm run dist
```

桌面回归验证：构建后运行 `npx electron tests/campus-ui.cjs`。使用独立测试数据和模拟 AI 返回，检查新旧用户引导、360×480 窗口、资料保存、补充回答、导入核对及无 Key 手动使用；不会读取真实用户任务或调用收费 API。设置环境变量 `CAMPUS_SMOKE_PACKAGE` 为 `win-unpacked` 路径可验证打包后的页面与 IPC。

运行 `npx electron tests/notice-ui.cjs` 验证重复通知、确认更新时间、过期预览保护、任务列表合并，以及实际原生窗口的完全隐藏和顶部唤出。可设置 `NOTICE_SMOKE_PACKAGE` 指向打包目录；使用独立数据及模拟 AI，不移动真实鼠标，最后短暂显示测试窗口验证原生可见性。

运行 `npx electron tests/reminder-ui.cjs` 验证提醒批次、回复排队及草稿、五分钟重试、完成 / 延后、旧通知点击、时间反馈、修改 / 撤销，以及快捷键聚焦、冲突回滚和 Esc。可设置 `REMINDER_SMOKE_PACKAGE` 指向打包目录。使用隔离数据、模拟 AI / 系统通知 / 快捷键注册，不占用个人快捷键或读取真实 Key；系统实际通知投递仍受 Windows 通知设置影响。

安装版生成于 `release/`。发行包只包含构建后的程序及必要依赖，不收录本机应用数据。
