# 轻任务 · 顶部滑出任务管家

一款 Windows 桌面待办工具，复刻经典 QQ 的顶部贴边体验：鼠标移到窗口所在位置的屏幕顶部，任务窗口自动滑出；移开后快速收回。支持自然语言添加任务、导入文档和截图、本地保存和提醒回复。

## 下载试用

适用于 Windows 10 / 11，64 位。试用者无需安装 Node.js 或下载源码。

**[前往 Releases 下载试用版](https://github.com/fahlim520/ZNT2/releases/latest)**

- `*安装版.exe`：安装版，可选择安装目录；安装完成后自动创建桌面和开始菜单快捷方式。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

首次启动会展示设置。可填写**自己的 DeepSeek API Key**，点击“测试连接”后保存；也可以先跳过，用“手动添加”创建任务。程序内及安装文件的产品名称为“轻任务”。

这是早期试用版，安装文件暂未进行代码签名。应用需要保持运行才能发出提醒；隐藏窗口后仍在系统托盘运行，通过托盘菜单“退出轻任务”可完全退出。

## 使用方式

- 鼠标移到窗口所在位置的屏幕顶部展开；移开后自动收回。也可点击顶部标签或托盘图标展开。
- 拖动标题区域或顶部标签，沿屏幕顶部移动窗口。
- 拖动右边调宽、底边调高、右下角同时调整宽高；位置和尺寸会自动保存。设置中可“恢复默认大小”。
- **Enter 发送，Shift+Enter 换行**；中文输入法确认选字时不会发送。
- 支持勾选完成、编辑、删除、搜索以及工作 / 生活 / 学习等分类。
- 点击“贴边自动隐藏”可固定展开，再点一次恢复自动隐藏。
- 设置中可选择伊藤橙（橙色）、酷安绿（绿色）、韵味紫（紫色）、哔哩粉（粉色）四种主题，并实时预览、保存选择。

## 文档与截图转待办（0.2.0）

- 把文件拖进展开的窗口，或点击输入框上方的“导入文件”。截图可以直接按 **Ctrl+V**，也可以点击“粘贴截图”。微信公众号通知可以截图后导入。
- 支持 **PDF、Word（DOCX / DOC）、PNG / JPG / JPEG / BMP / WebP 图片、TXT、Markdown、CSV**。不支持的格式请先导出为 PDF 或截图。
- 文字版 PDF 和 Word 在本地提取文字；扫描 PDF 与截图使用 Windows 本地 OCR。OCR 需要系统安装对应语言的“光学字符识别”组件，本机没有组件时会提示。
- 配置 Key 后，AI 从识别文字中整理多条待办。先核对任务、日期、提醒方式和来源摘录，可以修改或取消勾选，再点击“加入待办”。未配置 Key 也能提取文字并手动创建任务。
- 明确的“15:05 提醒我”保留该时刻；未指定提醒时间的明确截止时刻默认提前一小时。只有日期时，当天按小时提醒，未来日期在今天及中间各天安排一次，截止日按小时提醒。
- 缺少年份、相对日期缺少通知发布日期、已经过期或疑似重复的事项会提示核对，默认不勾选，避免把旧通知自动安排成今天的任务。
- 每批最多 8 个文件、每个 20 MB；每份 PDF 最多前 20 页，每批最多 5 万字和 40 条任务。超限会提示，长文件请分批导入。
- Word 内嵌图片暂不识别，请将图片另存或截图后单独导入。OCR 结果可以在预览中修正后重新整理。

## 提醒示例

日期和时间按中国时区 `Asia/Shanghai` 理解。

| 输入 | 提醒行为 |
| --- | --- |
| 今天 15.05 提醒我整理电脑 | 今天 15:05 提醒，不改成一小时后；若该时刻已过，运行中的应用会补提醒 |
| 今天我要整理电脑 | 创建今天的任务，通常在一小时后首次提醒；临近当天结束时会提前安排 |
| 明天下午 3 点开会 | 截止明天 15:00，默认 14:00 提醒 |
| 明天下午 3 点开会，提前 10 分钟提醒 | 明天 14:50 提醒 |
| 整理书架，不要提醒 | 保留待办，不安排提醒 |

提醒弹出后，可以回复“好”“OK”“我会执行的”将任务标记完成，或回复“30 分钟后再提醒我”“明天上午 9 点再提醒我”延后。没有回复时，五分钟后再次提醒。AI 解析失败会保留原始输入，供手动确认。

## 提醒提示音（0.3.2）

- 设置中可以开启或关闭自定义提醒提示音。
- 程序内置“冰、牛、哇哦”三个默认提示音，首次启动会放入音频文件夹，无需另行下载。已有自定义音频时保留原有文件；旧版的音频文件夹会优先迁入新目录。
- 点击设置中的“打开音频文件夹”，把自己的音频放进去即可。音频保存在当前 Windows 用户的应用数据目录中（`%APPDATA%\qing-task\reminder-audio`），避免向受 Windows 保护的“文档”目录写入；已有旧版音频会自动复制迁移，原文件保留。新增或删除音频后无需重启，下次提醒会重新读取。
- 支持 `.wav`、`.mp3`、`.m4a`、`.aac`、`.flac`、`.ogg` 和 `.webm`。按文件名排序，每次提醒播放一个文件，下一次提醒播放下一个，播到最后一个后回到第一个。可用 `01`、`02`、`03` 等文件名前缀控制顺序。
- 文件夹为空或暂时无法读取时，使用程序内置的默认音频。
- 三个默认音频随源码和安装包提供。用户自行添加的音频只保存在本机，不会上传到 DeepSeek 或 GitHub。

## API Key 与隐私

- 项目源码和发行包均不包含开发者的 API Key、个人任务或本机设置。每位使用者自行配置 Key，API 费用由自己的 DeepSeek 账号承担。
- Key 仅在 Electron 主进程使用，通过 Windows `safeStorage` 加密后保存在当前用户的应用数据目录；设置页可以修改或删除。
- 任务默认只保存在本机，没有账号系统或云端同步。
- 使用自然语言解析时，输入的任务描述和解析所需的当前时间会通过 HTTPS 发给 DeepSeek；测试连接也会向 DeepSeek 发送请求。手动添加任务不调用 AI。
- 文档和图片原件不上传。配置 Key 后，导入时提取的文字与文件名会发送给 DeepSeek；可以在预览中修改文字并重新整理。关闭导入不会保存候选任务，确认加入后只在本地保存任务和来源摘录。
- 本地配置、任务数据、日志和工作目录已加入 `.gitignore`。请不要在 Issue、截图、日志或代码中提交任何真实 Key。

## 本地开发

建议使用 Node.js 22 LTS，在 Windows PowerShell 中运行：

```powershell
git clone https://github.com/fahlim520/ZNT2.git
cd ZNT2
npm ci
npm run dev
```

如 Electron 运行包下载超时，请在网络恢复后重新运行 `npm ci`。开发运行仍需自己在设置页填写 Key，无需创建任何密钥文件。

## 验证与打包

```powershell
npm run typecheck
npm test
npm run dist
```

安装版生成于 `release/`。发行包只包含构建后的程序及必要依赖，不收录本机应用数据。
